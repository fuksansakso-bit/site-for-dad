# Локальные референсы PROJECT_NAME

Директория `reference/` хранит только исходные материалы для анализа и согласования. Она не является публичной медиатекой продукта и не должна автоматически публиковаться вместе с сайтом.

## Структура

### `reference/design/`

Визуальные референсы интерфейса: композиции, цветовые направления, типографика, motion-примеры, скриншоты и заметки об источнике.

### `reference/works/`

Фотографии реально выполненных работ владельца бизнеса, разрешённые для внутреннего анализа или публикации в портфолио.

### `reference/materials/`

Фотографии и сканы тканей, коллекций, цветов, механизмов, кассет, направляющих и других элементов реального ассортимента.

## Состояние на 2026-08-01

При первичной инвентаризации все три каталога были пусты. Изображения не анализировались, потому что локальные файлы отсутствовали. После добавления материалов инвентаризация и проверка прав MUST быть выполнены повторно.

Владелец бизнеса отдельно подтвердил разрешение на публикацию предоставленных им фотографий работ. Это разрешение относится к портфолио, но не превращает фотографии работ в точные texture/reference images материалов. Дополнительные фотографии ожидаются позднее; наличие оригиналов без водяных знаков пока не подтверждено. Поскольку файлов в репозитории при инвентаризации не было, связь разрешения с конкретными файлами MUST быть проверена после их добавления.

## Правила добавления

Каждый файл SHOULD иметь понятное имя без персональных данных, например `collection-code_color-code_source-date.ext` или `work_city-objecttype_year_sequence.ext` после утверждения схемы именования.

Для каждого внешнего материала MUST быть известны:

- источник и автор/правообладатель;
- дата получения;
- разрешённое назначение: анализ, публикация, обучение/обработка;
- условия лицензии и необходимая атрибуция;
- наличие людей, адресов, номеров телефонов или иной приватной информации;
- срок хранения и основание удаления, если применимо.

Если права или согласие неизвестны, файл MAY использоваться только для закрытого анализа и MUST NOT публиковаться либо передаваться внешнему AI-провайдеру до решения вопроса.

## Фотографии работ

- В `works/` допускаются только фотографии, полученные законно и с понятным разрешением на использование.
- Лица, точные адреса, документы, номера автомобилей и другие идентификаторы SHOULD быть исключены или обезличены.
- Исходник сохраняется отдельно от подготовленной публикационной версии, если это разрешено политикой хранения.
- Для предоставленных владельцем фотографий работ исходники MUST сохраняться; обработанные версии хранятся отдельно и не перезаписывают оригинал.
- Решение о публикации конкретной работы MUST быть трассируемо до согласия и статуса модерации.

## Изображения материалов

- Цвет на фотографии не считается точным эталоном без калиброванного процесса съёмки.
- Один вариант материала SHOULD иметь согласованный набор: общий вид, крупный план фактуры и при необходимости reference image для визуализатора.
- Изображение MUST быть связано с реальным вариантом/SKU только после проверки владельцем ассортимента.
- Нельзя выводить из имени файла цену, остаток или технические ограничения.

## Внешние веб-референсы

- [LAYEL](https://layel.ru/) рассматривается только как референс идеи короткого вступления: поле звёзд, ощущение движения и появление приветственного текста. Копирование бренда, текста, структуры, палитры или конкретной реализации запрещено.
- [Vengeance UI](https://www.vengenceui.com/) рассматривается как каталог отдельных motion/UI-паттернов. На дату проверки его [публичный репозиторий](https://github.com/Ashutoshx7/VengeanceUI) заявляет MIT License, но перед использованием MUST быть повторно проверены лицензия конкретной версии, происхождение зависимостей, copyright notice и условия атрибуции.

## Запреты

- Не изменять и не удалять исходные материалы без отдельного запроса владельца.
- Не коммитить пользовательские фотографии окон, маски или результаты приватной визуализации.
- Не использовать `reference/` как production object storage.
- Не очищать EXIF молча: сначала сохранить допустимый оригинал и зафиксировать процесс подготовки производной копии.
- Не переносить чужие тексты, логотипы, графику или код только на основании того, что они доступны в браузере.
