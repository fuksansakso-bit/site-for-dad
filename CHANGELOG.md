### Fixed

- The 2,048-material scale fixture now reuses the same hex value for every occurrence of one synthetic color identity, so the production fail-closed public-slug collision guard tests valid scale data instead of rejecting internally inconsistent fixture colors.
- The catalog synchronization integration gate now asserts the canonical route-safe public slug contract instead of the superseded Phase 1B.1 `amigo-category-*` prefix, keeping the test source-neutral after full-catalog slug normalization.
- Public-media acceptance now compares sampled response bytes with the server-side approved `MediaAsset.fileHash` selected by the public media ID; the public DTO continues to omit internal checksums/object locators while ETag and storage integrity are independently verified.

- Full-catalog category normalization now stores the adapter's bounded source slug and updates it idempotently; the public read model also deterministically normalizes retained immutable `category:path:` separators, so active v2 category paths satisfy the public URL/filter contract without changing source identity or provenance.

- The full-catalog acceptance gate now counts only source-price revisions pinned to the selected run's semantic `sourceVersion` and item hash, so retained Phase 1B.1 price history is not misclassified as duplicate Phase 1B.2 evidence.

- Phase 1B.2 exact-repeat versioning now recomputes a backward-compatible semantic checksum from safe source facts instead of persisted hash-format, recapture time or local media governance fields. Shared family/material/color representative provenance is deterministic/non-semantic, media-manifest identities normalize from stable reference IDs, and snapshot normalization uses a deterministic capture-key tie-breaker; a false-positive 1,795-difference repeat candidate was explicitly rejected without changing active v2.

- Phase 1B.2 publication preparation now covers every locally verified current-run material/category/system/model media reference instead of approving only objects reached through material placements; hash-deduplicated objects remain single records and active composition still controls delivery.

- Full-catalog media import now rebinds the unique material/role/order placement when the Phase 1B.2 parser identity supersedes a pilot source-media identity for the same slot. Historical source evidence remains retained, the current `SourceMediaAsset` becomes the placement provenance, and checksum-addressed object reuse avoids duplicate binaries; a supporting source-entity join index also prevents the first post-normalization media batch from depending on stale PostgreSQL planner statistics, while exhausted media retries now close the run and seal its partial manifest instead of leaving it stranded in `IMPORTING_MEDIA`.

- Устранена обнаруженная полным CI гонка двух immutable uploads одного object key: provider-neutral adapter сериализует записи по endpoint/bucket/key, сохраняет idempotent same-content behavior и возвращает `STORAGE_CONFLICT` для другого содержимого; повторный 15/15 storage gate и 9/9 CI прошли.
